Where your numbers live

Point Pulse at the system your team already uses every day. Pulse stores the link, never the data, and never a password. If the only honest answer for a number is "somebody types it in", that is worth knowing too - the freshness label on the card will say so.

Nothing here is a secret. A spreadsheet id names which document to open, the way a street address names a building. Every actual credential lives in the server environment and never reaches this page.
